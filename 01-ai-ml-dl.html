2. A Short History: Hype, Winters and Breakthroughs

AI progress came in waves. Blue outlined items are "AI winters": periods when funding and interest collapsed because results did not match promises.

Teaching takeaway: every wave was triggered by the same three ingredients improving: algorithms, data and compute. Deep learning exploded after 2012 because GPUs and large datasets arrived together.

3. Three Ways Machines Learn

Also worth knowing: semi-supervised learning uses a few labels plus lots of unlabeled data. Self-supervised learning creates its own labels from the data (for example, predicting the next word), which is how modern LLMs are pre-trained.

4. Hand-Written Rules vs Learning from Data

Traditional programming: Data + Rules → Answers. Machine learning flips it: Data + Answers → Rules.

Try it. Type a subject line and compare a rule-based spam filter with a tiny "learned" one.

Rule-based filter

Rule: if subject contains "free" or "winner" → spam

Learned filter (word weights)

Weights were learned from labelled emails. Score above 0 → spam.

Example 3 shows the point: the rule fires on "free" and wrongly flags a normal email. The learned model weighs all words, so "parking" and "venue" pull the score back. In real ML, those weights are found automatically by training, which is exactly what you will code in the hands-on labs.
