Data and Preprocessing

"Garbage in, garbage out." Models only learn what the data shows them. This module covers how to turn raw, messy data into clean numeric input that algorithms can actually use.

Clean inconsistent text, duplicates and wrong types
Choose a strategy for missing values and outliers
Encode categories as numbers correctly
Scale features and split data without leakage

1. Why Preprocessing Matters

Real data arrives with blank cells, typos, text where numbers should be, and columns on wildly different scales. Most algorithms need numbers only, without gaps, on comparable ranges.

The standard order of operations:

  1. Clean: fix types, duplicates, inconsistent text
  2. Split into train and test first
  3. Handle missing values and outliers (learn the fill values from train only)
  4. Encode categorical columns
  5. Scale numeric columns (fit on train only)
Golden rule: anything that learns from data (mean, median, min, max, category list) must be fitted on the training set only and then applied to the test set. Otherwise test information leaks into training.

2. Cleaning Messy Data

The same city appears as many different strings. The computer treats each spelling as a separate category. Click through the steps and watch the number of unique values fall.

df["city"] = df["city"].str.strip().str.title() df["city"] = df["city"].replace({"Chenai": "Chennai", "Bangalore": "Bengaluru"}) df = df.drop_duplicates() df["age"] = pd.to_numeric(df["age"], errors="coerce") # "N/A" becomes NaN

3. Missing Values and Outliers

Ten customers' ages. Two are blank and one entry says 120. Pick a strategy and watch what happens to the average age.

Rule of thumb: drop rows only when few are missing and the loss is random. Use the median when outliers or skew exist, the mean for symmetric data, and add a "was_missing" flag column when the absence itself carries meaning.
from sklearn.impute import SimpleImputer imp = SimpleImputer(strategy="median") X_train = imp.fit_transform(X_train) # learn the median from train only X_test = imp.transform(X_test) # reuse the same median

MethodFormulaUse when
Min-Max(x − min) / (max − min)You need a bounded 0–1 range (neural nets, image pixels). Sensitive to outliers.
Standardization(x − mean) / stdDefault choice for linear models, SVM, KNN, PCA.
No scaling—Tree-based models (decision tree, random forest, XGBoost) do not need it.
from sklearn.preprocessing import StandardScaler scaler = StandardScaler() X_train_s = scaler.fit_transform(X_train) # fit on train ONLY X_test_s = scaler.transform(X_test) # apply the same mean and std

7. Putting It Together: A Leak-Proof Pipeline

Scikit-learn's Pipeline and ColumnTransformer bundle every step so that fitting only ever touches training data.

from sklearn.pipeline import Pipeline from sklearn.compose import ColumnTransformer from sklearn.impute import SimpleImputer from sklearn.preprocessing import StandardScaler, OneHotEncoder from sklearn.linear_model import LogisticRegression num = Pipeline([("imp", SimpleImputer(strategy="median")), ("sc", StandardScaler())]) cat = Pipeline([("imp", SimpleImputer(strategy="most_frequent")), ("oh", OneHotEncoder(handle_unknown="ignore"))]) pre = ColumnTransformer([("num", num, num_cols), ("cat", cat, cat_cols)]) clf = Pipeline([("pre", pre), ("model", LogisticRegression())]) clf.fit(X_train, y_train) # everything fitted on train only print(clf.score(X_test, y_test)) # test data is only transformed
