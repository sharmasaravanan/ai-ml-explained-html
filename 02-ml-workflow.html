3. Train, Validation and Test: The Exam Analogy

A model must be judged on data it has never seen. Otherwise you only measure memory.

📘 Training set (≈60–70%)Textbook and practice problems. The model learns from this.
📝 Validation set (≈15–20%)Mock test. Used to compare models and tune settings (hyperparameters).
🎯 Test set (≈15–20%)The final exam. Touched once, at the very end, to report honest performance.
If you peek at the test set repeatedly while tuning, it silently becomes a second validation set and your final score will be too optimistic.

4. Danger Zone: Data Leakage

Leakage means the model sees information during training that it would not have at prediction time. Scores look amazing in the notebook and collapse in production.

Accuracy on the test set
Accuracy after deployment (real customers)
Other classic leaks: scaling or imputing on the full dataset before splitting; using future data in time-series; duplicate rows landing in both train and test; features derived from the label.
